# AI Agents Module

This directory is reserved for AI Agent orchestration to be implemented in subsequent phases:
- **Director Agent**: Parses song audio and lyrics into structured storyboards (`storyboard.contract.ts`).
- **Character / Rig Agent**: Designs planar 2.5D character rigs (`rig.contract.ts`).
- **Compositor Agent**: Controls transitions, lighting palettes, and audio-reactive effects.

In Phase 1, this module remains a minimal placeholder with zero external dependencies.
